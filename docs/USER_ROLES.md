# User roles

| Role | Primary workspace |
|---|---|
| Platform super administrator | Tenant creation, subscriptions, feature flags, users, integrations and audit |
| School owner/administrator | School setup, memberships, academic and operational oversight |
| Admissions officer | Applications, documents, decisions and enrolment conversion |
| Registrar | Students, guardians, enrolments, transfers and status changes |
| Teacher | Classes, attendance, assessments, marks, results and timetable |
| Accountant | Fee setup, invoices, payments, receipts, reconciliation and reports |
| HR/payroll officer | Staff, contracts, leave, components, payroll runs and payslips |
| Librarian | Catalogue, copies, circulation and fines |
| Nurse | Medical profiles, conditions, clinic visits and medication |
| Transport manager | Vehicles, routes, stops, trips and trip attendance |
| Boarding manager | Hostels, dormitories, beds, assignments and boarding attendance |
| Guardian | Linked children, attendance, published results, invoices and messages |
| Student | Timetable, attendance, published results, library and announcements |

Permissions remain configurable; role names are templates rather than hardcoded authorization logic.
